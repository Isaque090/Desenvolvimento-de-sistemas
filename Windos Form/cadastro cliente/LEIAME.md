# Cadastro de Cliente — Windows Forms (.NET Framework 4.7.2)

Abra `CadastroCliente.sln` no Visual Studio e pressione F5.

Componentes usados: MessageBox, Label, TextBox, Button, CheckBox, RadioButton, GroupBox, PictureBox.

Funcionalidades:
- **Carregar Imagem**: gera e exibe uma imagem fictícia no PictureBox.
- **Limpar Imagem**: remove a imagem do PictureBox.
- **CheckBoxes (E-Mail / Facebook / Twitter)**: habilitam a digitação do campo correspondente.
- **Incluir**: preenche todos os campos com informações fictícias e cadastra o nome.
- **Alterar**: atualiza o nome do último cliente cadastrado.
- **Consultar**: MessageBox com todos os nomes cadastrados; se não houver nenhum, avisa "Nenhum nome está no cadastro".
- **Excluir**: remove o cadastro após confirmação.
- **Limpar**: limpa todos os campos, seleções e a imagem.
- **Sair**: encerra a aplicação após confirmação.
