# Desenvolvimento de Sistemas

Repositório destinado para a matéria de Desenvolvimento de Sistemas, focado no aprendizado de lógica e criação de interfaces gráficas.

## 🚀 Tecnologias e Estruturas
* **Linguagem:** C# / .NET
* **Aplicações Console:** Exercícios de lógica de programação, estruturas de repetição e POO (Programação Orientada a Objetos).
* **Windows Forms (Desktop):** Desenvolvimento de telas, componentes visuais, eventos e sistemas com interface gráfica.
* **IDE:** Visual Studio

## 📂 Estrutura do Repositório
* `/Console`: Exercícios práticos executados diretamente no terminal/console.
* `/Windows Forms`: Projetos de sistemas de telas, cadastros e interfaces gráficas.
